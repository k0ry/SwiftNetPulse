International](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0).

The controlling license text is [LICENSE](LICENSE). The Russian page

second license.

## What this grants

CC BY 4.0 allows copying, redistribution, modification, and commercial use,
including in applications, provided attribution is given as described in the
license.

Patent and trademark rights are not licensed. The material is provided as-is.

## Documents

- `LICENSE` — official CC BY 4.0 legal code.
- `docs/ru/LICENSE.md` — informational Russian summary and links.
- README licensing section — short pointer to the same license.

There is no separate commercial license and no noncommercial-only draft.

## Note on Creative Commons and software

[Creative Commons](https://creativecommons.org/faq/) does not recommend CC
licenses as a substitute for software-specific licenses such as MIT or Apache
2.0, because CC licenses do not address patents in the way those licenses do.
CC BY 4.0 is used here because it is the chosen public license for this
repository.

## Attribution

When sharing SwiftNetPulse or an adaptation, retain the copyright notice, a
link to the license, and an indication of changes if you modified the material.
A reasonable form is: “SwiftNetPulse, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)”.
